# Home Lab TSSR — Kenny Bretille

Infrastructure virtuelle construite dans le cadre de ma formation
**Technicien Supérieur Systèmes et Réseaux** (ENI Ecole Informatique, 2026).

## Objectif

Pratiquer et consolider les compétences acquises en formation sur un
environnement simulant une infrastructure d'entreprise réelle.

## Stack technique

- **Hyperviseur :** VMware Workstation Pro (hôte Ubuntu)
- **Machine hôte :** AMD Ryzen 7 Pro — 32 GB RAM — 1 TO SSD
- **OS serveurs :** Debian 13, Windows Server 2022
- **Réseau :** pfSense CE
